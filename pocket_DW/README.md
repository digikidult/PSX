# Pocket Digimon World 繁體中文攻略

由照顧第一隻夥伴開始，查進化、讀懂日文問題，再學識揀對手和找收藏。數碼獸名稱優先使用香港慣用叫法，旁邊保留日文方便認畫面。

## 第一次用

打開 `index.html`，先選自己玩的Fire、Wind、Cool或Nature版本。下載包解壓後可直接離線閱讀；請保留整個資料夾，圖片和查表功能才會齊全。

- **想養指定數碼獸：** 在進化攻略揀目前夥伴，逐項準備能力、對戰、時間和照顧條件。
- **唔識日文問題：** 到對話選項找相近中文，對照問題及答案旁邊的日文。
- **打唔贏或練不動：** 查對手能力、傷害試算，以及連勝後加幅下降的說明。
- **對手未開放：** 按所需收藏的「查看取得方法」，跟地點及前置往前找。
- **想開Fire比多獸：** 查Fire的共通記憶碎片10，有Wind取得及回Fire使用的完整收藏路線。

## 更新現有攻略

使用「只需更新檔」時，把解壓後的檔案放回原攻略資料夾，覆蓋同名檔案，再重新整理頁面。第一次下載、或不確定手上版本是否齊全時，用完整包。

## 放到GitHub Pages

把本資料夾內所有檔案放到網站使用的資料夾，讓 `index.html` 位於入口位置；保留其他檔案和圖片原來的相對位置即可。

## 資料有甚麼要留意？

本頁以玩家步驟及查詢為主。時間未必等於現實經過的時間，部分跨版本操作和特殊情況仍未逐步實玩；相關提醒會放在需要注意的位置。

公式依據、測試數字、研究紀錄和未確認項目集中在 [資料與研究說明](SOURCES.md)。想知道某條規則從哪裏整理出來，可以到那裏查看。
