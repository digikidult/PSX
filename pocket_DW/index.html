YOUR FIRST PARTNER

由第一次玩，到識得自己規劃.

先跟着下面四步玩一次，再查進化表和對話卡。唔使先背熟所有數字。

01 / START

先分清兩邊用途：PocketStation主要是日常照顧、訓練與對話；回到PlayStation時，再處理主機選單中的進化確認、夥伴切換及資料管理。下面先由日常培育教起。

由蛋開始，要等幾耐？

有，本作會由數碼蛋經過兩段幼年期，再長成亞古獸等成長期夥伴。四版本可先按下面的遊戲時間等候，時間都由這次生命開始計：

成長過程由數碼蛋開始計
數碼蛋 → 幼年期Ⅰ（前段）約20秒
幼年期Ⅰ → 幼年期Ⅱ（後段）約40秒
幼年期Ⅱ → 成長期約60秒

怎樣讀：40秒是從一開始累積到40秒，不是孵化後再等40秒。幼年期不用套用亞古獸等成長期角色的能力門檻；到成長期後，再看下面的分歧進化表。

時間到了卻未變？先讓遊戲繼續運行，留意是否還有成長畫面未播完。表內是遊戲時間，不能直接用手機秒錶判斷；休眠及喚醒也可能影響你實際等候的時間。

長成成長期後，便可用下面的進化表，開始準備想要的下一隻。幼年期名稱與圖像仍在補充。

第一次玩：先做這四件事

  1. 確認版本與目前夥伴。在進化表選 Fire、Wind、Cool 或 Nature，再選你正在養的那隻。同一隻在不同版本，進化條件也可能不同。
  2. 先選一個下一階段目標。暫時不用直追最終進化。看看它要哪些能力、多少場對戰，以及能容許多少次照顧失誤。
  3. 一邊照顧，一邊訓練和對戰。夥伴叫你時先處理需要，睡覺時別打擾。再按目標補能力、累積對戰場數。
  4. 見到進化提示，回來看條件。提示出現後也要留意心情和照顧；拖下去，原本想要的進化可能會變。

先記住這幾個用語

≥ 就是「至少」；≤ 就是「不多於」。例如攻擊≥140，即140或以上；離家≤3，即最多三次。

HP／MP看最大值。進化表不是看當刻還剩多少HP或MP。

對戰場數包括敗仗。參戰25場，不等於一定要贏25場。

「本階段」由最近一次普通進化後開始計。養育時間則會繼續累積，回到數碼蛋才重新開始。

心情值不是好感度。數字較高不代表更開心；不同進化會要求不同範圍。

YOUR FIRST EVOLUTION · FIRE

跟一次：亞古獸 → 暴龍獸

以下用Fire版示範。目標是先養成暴龍獸，不需要一開始就研究合體或究極體。

  1. 先補齊四項能力：攻擊、防禦、智力、速度都要至少140。不要只練攻擊，另外三項未夠一樣不能達標。
  2. 累積至少25場對戰：計本階段打過的場數，不只計勝場。
  3. 留意心情與照顧：心情值最多7；打擾睡眠最多16次、忽略呼叫最多20次、離家最多10次。
  4. 等養育時間達48遊戲小時：這是遊戲中的時間，別直接當成現實兩日。
  5. 出現提示後確認進化：能力、時間、心情及照顧條件要一起滿足。若結果不同，按下方排查表逐項看。

第一次進化後，點樣再變強？

例如想走亞古獸 → 暴龍獸 → 機械暴龍獸 → 戰鬥暴龍獸，在每張卡按「下一步」，便可逐級查下去。

成為暴龍獸後，下一站機械暴龍獸要求養育時間至少96遊戲小時、四項能力各至少300、最大HP及MP各至少1300、心情值最多4，還有更嚴格的照顧與等候時間限制。完整條件見進化卡。

暴龍獸也有喪屍暴龍獸等其他分支，等候時間要求不同。想走機械暴龍獸，不能只看四項能力夠不夠。
這時要開始提早準備下一階段：能力未夠可以繼續培育，已經累積的照顧失誤卻不會因多練幾次就減少。普通進化後，這些照顧與參戰次數才會重新計。

點解仲未進化，或者變咗另一隻？

  1. 版本有沒有選錯？先看同一版本的條件。
  2. 是否漏了一項？能力、時間、心情及照顧限制缺一不可。
  3. 夥伴是否仍在離家？離家未結束時，不能走一般進化。
  4. 是否同時符合另一條路線？遊戲會先選優先次序較前的目標，並非由你直接點選想變哪一隻。
  5. 是否等得太久？某些進化有等候時間限制；出現進化提示後，不宜一直擱置。

EVOLUTION ROUTES

進化攻略.

先揀你而家養緊嗰隻，再看想變成哪隻。每張卡會告訴你要練甚麼、等多久，以及照顧上要留意甚麼。

02 / EVOLVE

看條件時，最容易誤會的地方

一張卡有兩個方法，怎樣看？先滿足「兩個方法都需要」的條件，再揀其中一個方法，完成該方法的全部要求。不是每項各揀一點拼在一起。

同時符合兩隻，會變哪隻？看卡上的「進化優先次序」，數字較小的先被選中。如果兩條路線一起達標，便先選數字較小的那條；準備目標時，也要看看前面有沒有另一隻容易先達標。

兩種時間有甚麼不同？「養育時間」從這次生命開始累積，普通進化不會歸零。「進化等候時間」只在夥伴達到可以進化的狀態時累積，普通進化後重新計。表中的「參考小時」不等於現實經過的小時，不同遊玩狀態會影響計時速度。

四屬性方法可不可以照做？先看自己的PocketStation版本：Cool／Nature會保留舊合體屬性，可分輪補齊；Fire／Wind每次會蓋過舊紀錄，不能照抄。詳見合體攻略，完整兩機操作仍待實測。

準備進化時要注意甚麼？查看當前心情、能力及照顧記錄，確認仍符合目標。普通進化後，心情回到7，照顧與參戰次數重新計；養育時間繼續累積。

數碼蛋與幼年期的時間參考見上面的「由蛋開始，要等幾耐？」；這裏則列成長期以後的分歧進化。

UNDERSTAND EVERY ANSWER

佢問緊乜？我應該點答？.

中文問題旁邊配上日文原句，每個答案亦逐項對照。先看中文理解意思，再用日文認出遊戲畫面上的那一句。

03 / DIALOGUE

選答案前，先問自己想達到甚麼

想維持某條進化路線，就先看它要求的心情範圍；想了解夥伴近況，就按對話意思回答。心情+1不一定是獎勵，心情−1也不一定是懲罰。例如暴龍獸需要心情≤7，心情值增加反而可能令你離開所需範圍。

不同夥伴有不同語氣，同一句也可能分幾行顯示。下面會把意思連起來寫，日文問題與選項會直接放在對應中文旁邊，方便逐項對照。

04 / CALENDAR
查看節日問題、中文選項及效果 →

到咗節日，點解佢仲未講？

  1. 先核對日期和時鐘。遊戲要認到當天日期，才有機會說節日對白。
  2. 留意平日最常互動的時段。可以留意早上7、8、9點，中午12、1點，以及傍晚6、7、8點。遊戲會參考你平日在哪個時段常陪它。
  3. 在適合時段等候。原版Fire要在選中的同一小時；Wind及Cool／Nature有時可前後放寬一小時，但不是每天都適用。
  4. 不是一到整點便保證出現。當天之前聊過的內容及次數也會影響機會；先前聊得多，可能會錯過這次節日對話。

同一個節日可以講幾次？

一般節日：完成後通常當天一次。

女兒節：可分兩至三段，要再等下一次對話機會，不會一次自動播完。

六月雨季：通常整個月一次，過了一日不會重新開始。

生日：通常當天一次；生日撞節日時，可能會先講生日而見不到原本節日內容。

可不可以讓夥伴習慣我的遊玩時間？

在上述時段，從普通照顧畫面打開選單，遊戲會記下互動。要保存該時段的記錄，應讓遊戲正常走到緊接的下一小時。

遊戲會偏向記錄最多的一個時段；同樣多時，較晚的一個時段優先。已保存的習慣不會單靠隔天重玩就重新累積，換日、跨月也會保留。

每隻夥伴分開記錄。繼續使用原有資料通常會保留習慣；重新建立夥伴資料則可能重來，不能把所有更換夥伴都當成同一種情況。

想打贏、練能力，定係搵收藏？.

在PS1挑戰對手、在PocketStation出門冒險，準備的方法不同。揀你而家想做的事，跟住查落去。

想在PS1多開幾個對手？

先查對手需要哪件收藏。不少對手要在PocketStation拿到指定收藏才會出現，單靠練高能力或不斷贏CPU未必開得到。

在下面選自己的光碟，將「顯示」改成「全部對手」，再按想挑戰那隻旁邊的「查看取得方法」。跟着地點和前置收藏去找，比盲目刷場數更直接。

Fire有42個對手，Wind有35個，Cool／Nature共用31個。這是對手名單，並非必須順序打完的關卡。

想在PocketStation搵人、搵物品？

路上遇敵靠機會，到城鎮找人則要看先後與前置。找指定收藏時，先用下面的收藏查詢，看看應該走路尋找，還是去城鎮打指定角色。

Fire有些道路對手會在你拿到獎品後不再出現。Wind、Cool及Nature的道路沒有隨機物品，想收集物品應先查城鎮角色，別只在路上來回走。

地名旁邊保留日文，方便認遊戲畫面；中文地名是本攻略的譯法。

先揀一個有機會打贏的對手

剛開始先看「初期可選對手」。比較攻擊、防禦和速度：打不痛就補攻擊，捱不起就補最大HP和防禦，經常後手便留意速度及所用招式。對手數值固定，不會因你練高了就跟着升。

同名數碼獸在不同光碟也可能有不同能力，記得先選對版本。

想找比多獸？Fire所需的記憶碎片10，要先在Wind取得；按收藏連結便可看完整路線。

打唔贏，先睇邊度出問題

下面講的是PS1對戰。先找最接近你遇到的情況，再決定練哪項能力、用甚麼招式。

「我速度高，點解仲係佢先出招？」

先手看角色速度加招式速度。夥伴本身快，用了慢招也可能後手；兩邊合計相同時才抽先後。差距很大時，後續出手機會也會受影響。

例如你速度200、招式速度80，合計280；對方速度250、招式速度10，合計260，這次便是你先手。

「點解一招打落去咁少血？」

先看招式威力、自己的攻擊和對手防禦，再看屬性。普通傷害由「威力＋攻擊－對方防禦」開始算；對方這輪沒有出招而防守，傷害還會再減半。

智力有助學招及迴避，並不直接增加這一下的傷害。想打得痛，不能只練智力。

我想睇詳細傷害、屬性與迴避規則
  1. 先算「招式威力＋自己的攻擊－對方防禦」。
  2. 按下面屬性表增加或減少傷害，每一步只保留整數。例如101加一半後是151；101減半後是51。
  3. 普通傷害最低為1。對方沒有出招而防守時再減半，最低仍為1。
  4. 對方成功避開便不扣血；打中時，扣血不會多過它當刻剩下的HP。
  5. PS1出招會消耗MP，揀招時要一起比較威力、招式速度及消耗。

由受招一方看屬性：先找左邊自己的屬性，再對上方打過來的招式屬性。

智力較高的一方較有機會避開：以受招者減去出招者的智力計，差1–400時約5%；401–500約10%；501–600約15%；601–700約20%；701–800約25%；801–900約30%。差距不大於0時，這項迴避機會為0。

換一招，會唔會打得好啲？

把雙方數值填進去，比較不同招式成功命中時的扣血、MP消耗和先手合計。想比較先後，可把雙方輪流填成出招者，再看哪邊合計較高。

試算假設已選用這招而且打中，不能預測電腦必定出哪招，也不能代替整場對戰。基本／後備攻擊不是可學招式。

「MP用晒，係咪只能捱打？」

未必，夥伴仍可能改用不耗MP的基本攻擊。Fire有這種補位；Wind及Cool／Nature在已確認的低MP情況也能轉用免費後備攻擊。這不是把原本昂貴的招式變成免費。

電腦會考慮剩餘MP和戰況，未必每次用最高威力的一招。準備長一點的戰鬥時，留意招式消耗，別只看威力。

目前未有可靠的MP自動回復時間。不要把「企定等幾秒就回MP」當成戰術前提；低MP後的表現亦可能隨招式和戰況不同。

「被打到郁唔到，係咪少咗一次出招？」

受擊動作未完，下一段動作會等一等；但不能就此當成失去一次攻擊。目前確認的普通受擊，沒有另外扣走一次出手機會。演出較長時，還可能要等HP條走完。

挨打後剩下的HP變了，電腦也可能改變選招。想知道為何後手，仍要比較角色速度和招式速度；不要只看哪隻先從受擊動作站穩。

點解Cool／Nature有時反應特別大？

Cool／Nature的這次傷害達到受招者最大HP四分之一，便會選較長的受擊反應；不足整數時向上計。例如最大HP1000，門檻是250；最大HP1001，門檻是251。

比較的是最大HP，不是目前剩下多少。只剩少量HP而被打倒時，演出另有處理，別用這個門檻預測倒下動作。Fire／Wind的普通受擊安排不同，不套用這條規則。

「演出勁啲，係咪一定有暴擊？」

演出長短不等於傷害高低。先比較招式威力、速度、MP和屬性，別只憑動畫揀招。目前也沒有足夠依據把這些演出當成麻痺、中毒或額外暴擊傷害。

每隻夥伴、每招實際要停幾秒，尚未量度；本頁不提供固定硬直秒數。

想靠對戰練能力，點揀對手？

先揀能穩定打贏的，再試高一階的對手。進入能力加成時，同階或較低階每項基礎加1–3；高一階加3–5，高兩階加6–8，高三階加10–15。最大HP、最大MP、攻擊、防禦、智力和速度各自計算。

CPU勝出後，約一半機會才會加能力。所以偶爾贏了沒有增長，未必是你做錯；通過這次抽選後，還會受到連勝及能力上限影響。Fire的雙卡對戰不套用這一次CPU抽選。

「初時有加，點解愈打愈少？」

連勝會令加幅下降。以下用連勝由0開始、打同階或較低階、沒有額外場景加成的情況作例子；數字只表示這次有獲得能力加成時，每一項能加多少。

「輸咗，仲有沒有機會學招？」

有機會，敗方戰後也會檢查新招。要先有本場留下的學習機會、智力夠高，而且尚未學過那招，才會出現待確認的新招；不是打一場就能學對手的任何招式。

見到學招提示後，照遊戲步驟確認、需要時選一招忘記，最後正常保存。也可以到下面的學招表查看智力要求。

PocketStation出門前：呢條路會遇到誰？

選版本和道路，先看看對手能力。想累積參戰，可以比較各路的遇敵機會；想找特定收藏，則直接看獎品和取得方法。

百分比是每次路上事件判斷的機會參考，不代表每走一次便必定遇到。相同數碼獸也可能有不同能力和獎品，請逐行比較。

去到城鎮，點解見唔到想搵嗰隻？

先看看排在它前面的角色。只要前面那隻符合條件、你又未拿過它的獎品，遊戲便先讓你遇到它。拿完前面的獎品，再回來找下一隻。

如果目標還需要另一件收藏，就要先去拿；在同一城鎮反覆碰運氣，不能跳過這項要求。

想要呢件收藏：去邊度、先打誰？

選你需要的收藏，跟着地點找角色。看到「先取得」就展開，一路往前查到自己已經能做的那一步。

打贏後要讀完結果對話，拿到獎品再保存。同一件不會重複送；已經持有時，城鎮也可能改為讓你遇到後面的角色。

Fire記憶碎片10有Wind的跨版本取得路線。查看時要連同「共通收藏／追加收藏」一起認，避免把同名同號的物品當成同一件。

卡住時，照住呢個次序查

  1. 對手未開放：在全部對手名單查所需收藏，再跟取得方法走。
  2. 城鎮見不到目標：先拿前面角色的獎品，再補齊目標的前置收藏。
  3. 打不贏：比較攻防和速度，回去按差距訓練，別只是不斷重打。
  4. 打贏卻不長能力：先排除偶爾沒抽中加成，再留意連勝衰減及能力上限。

先知道：合體會重新開始一輪培育

一般Pocket Digimon World夥伴互相合體後，會從自己版本的起步夥伴中選結果，並留下雙方屬性和合體次數。不要把它當成「任選兩隻，立即變成指定究極體」。想要的高階進化，仍要在之後滿足進化卡上的能力、照顧及合體要求。

下面把已知玩法及版本差別分開說明。兩部實體PocketStation的完整通訊、畫面確認和保存流程尚未逐步實測；實際操作時，請以兩邊遊戲提示為準。

開始前，要準備甚麼？

  1. 先查目標進化卡。記下它要Fire＋Wind、Nature＋Cool，還是四種屬性，以及合體次數要多少。

  4. 留意想保留的招式。合體時招式可能被取捨，接回PS1後清單亦可能再變；不要只為傳一招，就假定必定留得住。

最重要的版本差別：屬性會唔會一直儲落去？

PocketStation版本這次合體後留下甚麼？想集齊四屬性時
Fire／Wind記錄本次自己與對方的主屬性，蓋過舊的合體屬性紀錄。反覆跟不同屬性合體，不能靠這個方法越儲越多。進化卡有其他方法時，先選另一個。
Cool／Nature保留之前的合體屬性，再加入本次雙方主屬性。可以規劃分幾輪補齊缺少的屬性；每輪仍要完成主機更新及重新培育。

合體屬性不是招式屬性。學會Fire招式，不等於拿到Fire合體紀錄；想補哪一種，就要看合體對象本身的主屬性。

例子：Cool的屬性紀錄怎樣累積？
  1. 自己是Cool，先與Fire對象完成合體，紀錄有Cool＋Fire。
  2. 回主機更新，再培育到能合體，與Wind對象完成下一次，加入Wind。
  3. 再完成一輪更新與培育，與Nature對象合體，四種屬性便齊。
  4. 上面只是三次合體。屬性齊全與合體次數是兩回事，別把四種屬性當成已做了四次。

這是屬性累積的示意，完整兩機互傳與每輪培育仍未逐步實玩。進化表中要求四屬性的方法在Fire／Wind；即使Cool／Nature儲齊，如何正常帶到指定Fire／Wind夥伴仍未確認。因此初次培育，先揀進化卡中不用四屬性的其他方法。

合體後，能力與招式會點？

對方不是把整套能力送給你。PocketStation交換的合體資料包括身份、種類、主屬性及招式；新一輪能力還要看回PS1後的處理。

接回的PS1光碟已確認的舊能力繼承部分
原版Fire自己的合體前能力先取約15%，再加新一輪起始能力；小數捨去，這份舊能力每項最低保留1。
Wind／Cool・Nature新一輪起始能力再加上自己合體前的能力，之後仍受上限限制。

這裏比較最大HP、最大MP、攻擊、防禦、智力和速度，不是兩隻數碼獸的能力直接相加。新起始值未必每次相同，表格也不是保證合體後的最後數字。PocketStation屬性紀錄看程式版本；回收能力的表格則看PS1光碟。跨版讀取雖可使用，混搭回收合體資料的各種情況尚未全部確認，先用對應光碟完成這一輪。

招式先合併、刪除重複，最多八招。超過八招時會隨機取捨。Wind、Cool及Nature接收對方八招時，只會取對方清單的前七招參與這一步；即使未超過八招，也不要假定對方整套都會傳過來。

接回PS1更新後，招式清單還會再處理；因此PocketStation剛合體時的清單，不保證全部成為新夥伴的最終招式。更新完成後記得逐招查看。

點樣用合體準備指定進化？

  1. 先看那張進化卡有幾個方法。如果有不用合體的另一方法，可以比較哪個更適合手上夥伴。
  2. 先配屬性，再看次數。Fire＋Wind與四屬性是不同要求；合體次數夠了，也不會自動補齊缺少的屬性。
  3. 接回主機後再核對。後續版本這次更新會保留合體屬性與次數，並重新開始養育、照顧及互動時段記錄；舊的照顧習慣不一定沿用。
  4. 重新把其他條件養好。能力、心情、對戰場數及進化等候時間，仍要一起符合目標，合體紀錄不能代替它們。
