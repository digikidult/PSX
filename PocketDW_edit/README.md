# Pocket Digimon World 網頁版存檔修改器 0.12.1

繁體中文介面，沿用DigiKidult風格。下載整個資料夾後直接開啟index.html，亦可把資料夾內容放上GitHub Pages；不需要伺服器或套件安裝。

## 使用

1. 在遊戲正常保存，關閉模擬器；PK201先匯出FROM。
2. 選擇128KB原始記憶卡，先下載原檔備份。
3. 逐個選擇已有資料的夥伴位置，為同版本的活動／休止夥伴選目標及模式，按「自動配好進化條件」。
4. 查看五個位置的目標及全部修改清單，一次下載整張修改版卡檔。
5. 用副本在模擬器載入、保存，退出再開核對；保留原檔供還原。

檔案全程在本機瀏覽器處理，程式沒有上傳、外部API、追蹤或CDN依賴。備份和修改版是兩個不同的下載檔，沒有直接寫入原始檔案的介面。

## 支援

- 已驗證的Fire、Wind、Cool、Nature指定原版程式及15格MCX0遊戲檔。
- 128KiB原始卡檔，包括常見.mcd、.mcr及PK201的FROM。其他容器或單一遊戲匯出檔未支援。
- 最大HP／MP輸入1–9999，攻擊／防禦／智力／速度0–999，心情0–15。
- 已學招式修改保留1–8招；新增只列共通及目前屬性，已有跨屬性招式可保留。新招式正在等待確認時鎖定清單。
- 進化等候累積可設0–48參考小時，另可精細調整原始計數。原版同時有時間上限及下限，調得越高不一定越好。

直接更換只限下列 Fire／Wind／Cool／Nature 測試範圍；不強制進化、不切換活動夥伴；姓名、身份、未明旗標均保留；合體及照顧紀錄會按手動輸入或你套用的指定進化方案修改，全部列入預覽；只有明確選擇直接更換時，才會更新目標圖像，並按需要同步適用對話。幼年期、離家中、特殊生命狀態或不相符的資源組別，不提供一般進化等候調整。

## 對戰紀錄（0.2 新增）

四項計數可設 0–255：連勝相關計數、勝率用勝場、連敗相關計數及參戰計數。勝率用勝場不得多於參戰計數；介面提供整數百分比。修改後會重新預覽進化條件。

Fire／Wind 的 PS1 勝利流程有特殊處理：連勝相關計數加 2，勝率用勝場不增加（Fire 有實際勝場樣本；Wind 為原版程式驗證）。Cool PS1 及已測 PocketStation 勝利流程各加 1。連敗相關計數不是終身敗場，故不提供會誤導的「總敗場」欄位。原始計數範圍並不代表遊戲會在每種情境自然達到所有數值。

## 驗證與限制

瀏覽器的進化預覽直接執行卡內已辨認的原版Thumb判定，與391項獨立研究案例交叉核對。它比較目前條件及原版優先次序，並非完整PS1介面、強制進化或現實時間模擬。

卡檔沿真正的區塊連結讀寫，支援非連續區塊；輸出只准改指定位置，再次驗證版本、結構、資料及差異範圍。降低最大HP／MP時若目前值高於新上限，會在預覽列出一併調整。

目前為測試版：已進行程式及檔案層面的測試，尚未完成所有功能及三版的全面遊玩驗收。不是所有遊戲旗標都已解明；未解位置不供編輯。

中文招式名是閱讀譯名，保留日文對照，不宣稱所有名稱已核對為香港官方譯名。數碼獸使用既有攻略中的香港名稱與sprite參考。

## 檔案

index.html、style.css、app.js為介面；core.js為只改指定欄位的讀寫與驗證；evolution-vm.js執行原版進化條件；data.js提供已驗證指紋、限制和名稱。assets內為既有研究的sprite及DigiKidult標誌。

原卡檔、ROM及BIOS不包含在此網頁資料夾。

只接受已驗證的原版程式、目前夥伴圖像及與種類配對的對話。每項資料及輸出均重新核對。幼年期請先正常成長並保存；特殊生命狀態、離家、待確認招式、休止夥伴及跨版本更換均不開放。四版仍不能互相跨版本更換。

## 育成時間與進化等候（0.7 新增提示）

更換區現在顯示唯讀的「參考育成時間」。這是出生以來累積的育成值，與進化等候累積不同；更換種類時兩者都保留。一般年齡沒有開放自由修改；只有下方「回到 PS1 正式進化」的限定方案可補至門檻。換算的日／時／分／秒是遊戲內參考值，不是現實遊玩時長，也不是 PocketStation 的日期時鐘。

原版一般年齡更新在336參考小時（14參考日）後可能觸發生命結束，720參考小時（30參考日）達上限。不同遊戲狀態仍會影響實際更新，不能把它當作現實時間倒數。介面會在已達門檻時提示：更換種類不會重設年齡或延長壽命。

若直接更換後，卡內原版進化判定仍選中另一個目標，介面也會提示。直接更換不會把種類鎖定；提示只是目前條件的判定，不保證下一畫面立即進化。

### Fire 例：亞古獸改成暴龍獸，再進化機械暴龍獸

原版要求兩個時間條件同時符合：

| 資料 | 條件 |
|---|---|
| 從出生累積的育成時間 | 至少96參考小時，即4參考日 |
| 進化等候累積 | 在24參考小時的上限內 |

不是換成暴龍獸後重新等待96小時。若本來育成時間只有10參考小時，換成暴龍獸仍是10；把進化等候設為0也不會補足育成時間。

其他條件包括最大HP／MP各至少1300，攻擊／防禦／智力／速度各至少300，心情值0至4；打擾睡眠不超過5次、忽略呼喚不超過6次、離家不超過10次。超出等候上限後，原版可能改選其他路線，請看修改後的目標預覽。

## Nature 支援及驗收來源（0.8 新增）

Nature 現在也支援能力、心情、招式、對戰紀錄、進化等候調整、原版進化預覽，以及17隻同版本數碼獸直接更換。圖像及需要的對話會同步配對；保留原版Nature程式、原年齡和其他紀錄。

請選擇 `Nature-Partner-Resources-v1.local.json`。Fire v1、Wind v1及Cool v2資料全部沿用，不需重製。Cool與Nature雖然同一張光碟，但使用獨立程式及資源，修改器會結合程式和夥伴資料辨識；不能直接把Cool卡當作Nature更換。

Nature已核對原版程式、17份圖像及三套對話。這次實際驗收從明確標記的參考卡開始：使用原版Nature程式／圖像／對話，沿用已知共同存檔格式的成熟測試狀態，並非直接由PS1生成的原始Nature下載。目前尚未另外收集由PS1從零建立／下載的Nature原始卡。

此參考卡經網頁更換甲蟲獸→巴魯獸後，用戶已在PK201確認圖像、一段完整心情對話及返回、實際保存，以及程序重開後仍是巴魯獸；匯出卡的Nature程式、圖像及對話逐byte保留。其餘16個目標、反向及其他分支未逐一遊玩驗收。未知或不相符的程式／存檔仍只供查看，請先使用副本並保留原檔。

## 回到 PS1 正式進化：四版自動配搭（0.11）

選定目前種類的合法下一階，工具會**一併配好所需合體屬性、合體次數、能力、心情、參戰計數、照顧紀錄、育成及進化等候累積**，然後用卡內完整原版進化表核對目標。玩家不用自己逐項找數值。

支援125組指定來源→目標配對：Fire39、Wind36、Cool25、Nature25；共162條有指定來源的條件列。同一配對可能有多種達成方法，會可選「改動最少」或「盡量保留能力」模式。前者優先更少欄位改動，再比較數值差距（時間以參考小時、屬性以勾選變動數換算）；後者保留或提高六項能力，若做不到會提示，不會自行改用降低能力方案。已輸入的手動修改亦會作為偏好；需要時仍會改動以達標，全部在預覽列明。不會無必要地設定每個合體欄位：原版若有不需合體紀錄的合法替代方法，工具可選該方法。

1. 正常保存、關閉模擬器，再載入卡檔。五個位置會顯示原有種類、sprite、活動／休止狀態和已套用的目標。
2. 選擇一個已有資料的同版本位置，在「回到 PS1 正式進化」選目標及配搭方式，再查看所需／原檔／套用後。
3. 按「自動配好進化條件」，再到其他位置設定其餘夥伴。每位的目標及模式各自保留；最後核對整張卡的修改，一次下載。不需要更換用資源包。
4. 以PS1遊戲載入副本，逐隻正常切換夥伴、讓遊戲更新程式／圖像／對話配套，再選「進化」並確認。修改器不會代你切換活動狀態；種類及進化後能力由遊戲處理。
5. 完成保存及重開核對。要繼續向上進化，必須先完成本次進化及保存，再載入新存檔。

不提供跳級、跨版本、無關路線、回傳目前種類本身的目標，亦不把10條通用後備規則當成任選下一階。原版有其他路線優先時會調整條件避開；最終判定不是指定目標就停止下載。不能同時直接更換數碼獸。

保留目前種類、程式、圖像、對話、身份、主屬性、合體對象、招式、未知旗標。合體屬性只改已辨認的四個屬性位元，其他位元保留。合體及照顧紀錄會按方案修改，不代表曾在遊戲真正完成過這些事件。勝率用勝場保留，參戰計數不會低於它。降低最大HP／MP時，若目前值超出新上限，會一併調低並列入修改清單。

育成年齡只可保留或增加，不會降低、重生或延長壽命；方案限336參考小時前的一般狀態。進化等候可調整0–48參考小時，並核對原版512計數量化邊界；參考時間不是現實時間保證。幼年期、離家、待確認招式、特殊生命狀態或未知程式不提供方案；無可用方案時顯示原因。

取消標記只撤回方案補足的育成累積，其餘已套用數值仍保留；完全撤回請按「還原這位夥伴」。

**驗證範圍：** 四版125組配對以原版資源製作的合成來源副本全部產生方案、輸出並重新解析，原版PS1與PocketStation完整判定分別執行且目標一致。另測125組高能力／高育成／高紀錄狀態、第五夥伴槽、時間邊界、已達標不改數值、跳級／特殊狀態保護，以及實際瀏覽器下載。Nature來源仍有參考卡組合的限制，見上節。

## 合體及照顧紀錄（0.10）

新增四種合體屬性勾選、合體次數、打擾睡眠次數、忽略呼叫次數、離家次數。四種屬性可組合；四項次數均可設0–255，屬於原版計數，不等同終身紀錄。手動修改時，次數和屬性各自設定；0.11的指定進化方案則會按原版條件自動配搭。

所有原值、修改值會在下方列出，進化預覽會連同紀錄重新計算。這不會執行合體、更換目前屬性／版本、改寫合體對象或終止離家；姓名、身份、其他旗標及未選欄位保留。屬性紀錄只開放已辨認的四個屬性位元，其他位元保留。

幼年期、離家、特殊生命狀態或版本／資源不符時，這組欄位暫停編輯。也可直接套用指定進化方案，讓工具配好照顧與合體紀錄；套用後若手動修改導致目標不符，會停止輸出，請重新套用或取消標記。不能藉此跳級或直接換種類。

驗證包括四版全部16種屬性組合、各欄位上下限、保留其他位元／資料、172條原版條件列的已核對測試狀態，以及實際瀏覽器下載、原版PocketStation載入／保存／重載。此外，合體屬性／次數與照顧紀錄已隨上述六組抽樣通過實際PS1進化、保存及重開；未擴大為所有紀錄組合、125組配對或完整遊戲流程驗收。請用副本測試。

## 多夥伴與兩種配搭方式（0.12）

- 卡內已有資料的五個位置，可分別設定進化目標，再一次輸出。活動／休止狀態、身份及原來種類保留；空位不能新增夥伴。
- 五個位置直接顯示sprite、名稱、位置編號、活動／休止、是否有修改、已套用目標與模式。手機亦顯示全部五格，無需橫向尋找其他位置。
- 休止夥伴只開放與卡內目前程式相同版本的正常進化方案；不同版本、幼年期、離家、待確認招式或特殊狀態仍受限制。直接更換功能仍只限活動夥伴。
- 「改動最少」可以降低能力，以避開優先路線；「盡量保留能力」不降低原有或目前已輸入的六項能力。找不到不降能力方案時顯示原因，可手動改選另一模式。
