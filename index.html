按目標檢查能力、心情、參戰及照顧次數。參戰次數計算打過多少場，不只計勝場；表內HP及MP指最大值。

03

有進化提示便重新核對

進化執行時會重新判定目標；提示出現後，能力、心情、時間或照顧次數再變，結果亦可能改變。

日常遊玩的檢查次序

  1. 回應夥伴呼叫，按狀況照顧，避免忽略呼叫或打擾睡眠累積超過目標上限。
  2. 依進化目標安排訓練與參戰；對話選訓練方向，不會立刻得到相同數字的能力加成。
  3. 想收集節日對話，留意裝置日期與平日互動時段；日期正確仍不保證立即出現。
  4. 進化前再次查條件及較前的路線，完成後重新累積該階段的參戰與照顧記錄。

最容易看錯的三件事

心情不是越高越好。0至15是內部狀態值，不是一般好感度；有些路線反而要求較高數值。

養育時間與進化就緒計時不同。前者是該次生命累積的遊戲顯示時間，普通進化不歸零；後者只在符合就緒狀態時累積。

選項語氣不等於效果。同樣友善的回答，也可能設為不同固定心情值。先看效果，再按目標選擇。

02 / EVOLVE

怎樣看時間、心情及合體條件？

累積養育時間：按遊戲顯示小時計。一般進化保留，回到蛋重新開始。不能直接以關機或開機經過的現實時間換算。

進化就緒累積值：表中的「小時等值」是內部門檻的換算名稱；不同更新模式下，與養育時間的增加速度可不同。不要把「≤6小時等值」讀作現實六小時的期限。普通進化會把這個值歸零。

照顧及參戰：普通進化會重設忽略呼叫、離家、睡眠受擾及參戰等計數，心情設為7；離家中的計時未結束會擋住一般進化檢查。

合體屬性：「須包含」表示指定屬性都要存在，仍要滿足同列其他要求。標示「四屬性路徑」的規則可由程式接受，但正常遊玩怎樣取得全部四種記錄尚未核實，請勿當成已完成的速成操作方法。

數字型上限受原始計數的取整方式影響；邊界不要只按畫面整點估算。此表不提供尚未核實的初生數碼蛋、幼年期按鍵流程或保證成功的合體配方。

FIRE EXAMPLE

例：亞古獸 → 暴龍獸

累積養育時間≥48個顯示小時；攻擊、防禦、智力、速度各≥140；心情≤7；本階段參戰≥25次；睡眠受擾≤16次、忽略呼叫≤20次、離家≤10次。

若能力夠但沒有得到預期進化，按次序查心情、參戰、照顧記錄及是否仍在離家；不要只繼續增加攻擊。亞古獸的其他成熟期條件可在上表搜尋比較。

03 / DIALOGUE

先讀懂心情

內部值已核對的對白傾向
0–2「你問我心情？梗係好啦。」
3–7「我唔會灰心，仲可以繼續努力。」
8–11暫時不想傾偈，或叫玩家不要打擾。
12–15開始覺得寂寞。

對白分類不等同畫面有精確數值讀數。數值用來理解條件，不能將「心情+1」一律視為好處。

煩惱與和解

普通煩惱對話中，已測路徑選「そうだね／係呀」使心情−1；選「むりだよ／冇可能㗎」使心情+1。查詢心情本身不改數值。

心情在0或15、改談相處不順時，「ごめん／對唔住」使0→1、15→14；「さよなら／再見」在已測分支保持原值。這段說「想走」不等於真正離家。

實際離家提案：「だめだよ／唔得」不啟動離家；「いいよ／好呀」啟動離家計時並增加離家次數。回來後選「いいよ／好呀」心情設7；「いやだよ／唔制」設15，兩者最大HP均+50（上限9999）。

一般遊玩時，何時會提出離家？

已追查的正常更新分支要求：目前沒有離家計時、照顧狀態代碼小於9、心情剛好0或15，另通過隨機檢查。狀態代碼尚未逐一對應畫面，不代表成長階段。

隨機條件在32種低位結果中只有1種通過，但未換算成每秒、每次談話或每趟旅程的機率。離家期間建議入口會改顯示留言，不能照常談建議；離家計時的現實長度未核實，不以「一小時」寫死。

有數值變化的節日選項

日期日文選項／翻譯效果
2月14日ひみつ／秘密心情+1；只在相應玩家資料分支出現
5月5日なにも／冇乜嘢最大HP+10、最大MP+10、心情−1
11月25日さむがりめ／你咁怕凍嘅心情+1

HP、MP各最高9999，心情限制0至15。這些是已核對分支的效果；「不變」不代表事件完成記錄或後續對白不變。

等不到節日對話？

  1. 先核對裝置日期與時鐘，並讓遊戲正常更新。
  2. 互動時段候選為07、08、09、12、13、18、19、20時，最高有效分數的時段優先；同分時較後的一項優先。
  3. 原版Fire要求與目標小時相同；Wind、Cool／Nature另有附帶條件的前後一小時窗口，不能當成所有日子均適用。
  4. 入口還要隨機回傳值為0、共享對話計數小於5，並且沒有另一特殊對話狀態。這不是「全日只可談五次」。

同一天會重複嗎？

一般指定日期：完成後通常同日一次；再次符合入口時會轉一般對話。

3月3日：女兒節分兩至三段，要多次成功進入，不是一次自動播完。

六月：雨季記錄跨日保留，跨月才清除，正常情況是每月一次。

生日：一般同日一次，且腳本先判生日。生日撞固定節日時可能重複生日對話；不當成保證可刷獎勵的方法。

遊戲怎樣記住我的互動時段？

普通照顧畫面中，在上述候選小時內有效「開啟選單」的輸入會增加該時段分數，每次+1，最高63；在選單內移動或確認不屬於這次記錄。按住不放亦不會持續逐幀加分。

讓遊戲正常更新到緊接的下一小時，便會保存前一時段。已保存後，這條普通操作路徑不再替它加分；換日、跨月也不清除。重新啟動時，尚未保存的時段會清掉。

各角色資料槽分別保存習慣。沿用原槽會帶回原值，重新建立資料可能清零；不能把所有更換夥伴都視為重學時段。這裏沒有提供改時鐘或刪除資料重設的操作指示。

05 / MOVES

先過資格

招式屬性組要完全相同、未學過，並達到最低智力。屬性不是「包含某一位」便算相符。

不是隨機抽一招

合資格招式中，選智力門檻最高者；門檻相同選ID較小者。沒有合資格招式便不會由此程序選出新招。

最多八招

未滿八招時加在清單最後。滿格不會直接覆蓋或變成九招，須先忘記一招；取消則保留原清單。

完整忘招畫面的游標、按鍵流程尚未核對。本表門檻適用於已抽取的選招程序，不等於所有獲得方式或初始招式。技名保留日文，未把直譯當作香港官方招式名。
